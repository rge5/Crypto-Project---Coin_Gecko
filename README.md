# 🚀 Crypto Tracker | React Cryptocurrency Dashboard

A responsive cryptocurrency tracking web application built with **React.js** that displays cryptocurrency market data, interactive price charts, and detailed coin information. The application helps users explore the crypto market through a dark-themed interface with search, filtering, and historical price visualization.

## ✨ Features

- 📊 **Live Cryptocurrency Market Data** — Fetch cryptocurrency prices and market information from an external API.
- 💰 **Market Overview** — Display coin prices, 24-hour price changes, and market capitalization.
- 📈 **Interactive Price Charts** — Visualize historical cryptocurrency prices using Chart.js.
- 🔎 **Search & Filtering** — Find cryptocurrencies using the implemented search and filtering functionality.
- 🪙 **Coin Details Page** — Explore individual cryptocurrency information, including descriptions and price history.
- 📅 **Chart Time Range Selection** — Change the displayed historical price period using the available selector.
- 📱 **Responsive UI** — Support different screen sizes with a responsive layout.
- ⏳ **Loading States** — Provide feedback while cryptocurrency data is being fetched.
- ⚠️ **Error Handling** — Handle data-fetching errors to improve the user experience.

## ⚙️ Installation & Setup

### Prerequisites

- Node.js and npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/rge5/Crypto-Project---Coin_Gecko.git
```

### 2. Navigate to the project directory

```bash
cd Crypto-Project---Coin_Gecko
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

## 🔌 API Integration

The application retrieves cryptocurrency market data from an external API and uses the response to populate the dashboard and coin details views.

The fetched data supports market information, price history, and chart visualization. Loading and error states help manage asynchronous data requests.
